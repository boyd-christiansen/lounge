# Progress

## Public baseline — 2026-11-02

Lounge is a local desktop attention queue for parallel agents. The public baseline contains the application, tests, build scripts and generic documentation. Private pre-publication development history remains local. Queue contents, source snapshots, source identifiers, credentials and browser drafts are excluded from this repository.

Implemented: durable SQLite state; priority and manual ordering; task-level and project-level work/personal classification; snooze and resurfacing; explicit remove/undo; draft and displayed-question binding; Codex app-server and Claude Code SDK execution; optional local coordination; scoped existing-Claude bridge; one-conversation import preview/confirmation; native source handoff; grounded decision briefs with exact alternatives; repeat-visit summaries; system and ElevenLabs read-aloud; completed-dictation submission; bundled Mac application.

The entry flow opens a personalized spoken greeting and a composer. The user can say to start the queue, add a task or find a conversation. Source briefings and narration prefetch independently. Background updates cannot enter the queue until the user chooses it. The room remains one scene with its queue/settings in the left drawer.

Design review: see [DESIGN.md](DESIGN.md). Public release checks and final verification are recorded below when completed.

## 0.6.0 — automatic preferences and explicit queue controls

Removed routine Save actions. Voice and other preference selections save immediately, text and project notes save after a short edit debounce, and model/effort choices save for the next turn. Writes are serialized with field-scoped patches; newer edits overlay incoming state. Pending non-credential edits stay in browser-local storage across reloads. Errors surface a quiet status and Retry, which refreshes the local session capability before retrying. API credentials and connection actions remain explicit.

Replaced Automatic order with Most recent, Least recent and Priority. Project grouping remains the outer queue. Manual moves show Custom; selecting a named sort atomically replaces both drag overrides with revision guards. Conversation activity is distinct from polling and cached summaries. The coordinator exposes the same sort and project-filter controls, upgrading idle conductors to tool contract 12.

Queue states distinguish questions, approvals, working, ready results, already-presented next steps, paused work, errors and unverifiable snapshots. Presentation is tied to a result version and never removes a task. A briefing that changes while being prepared is refreshed before presentation. Added explanatory control hints and visible shortcut keycaps beside project filters and drawer navigation.

## 0.8.0 — responsive intake, dictation holds and durable discovery

The first dictation-key press now holds playback across key release and repeated taps. It also suppresses automatic task changes and new readouts until text arrives or the user explicitly resumes. Space resumes with an empty composer, including when that empty field is focused; it remains a normal space inside a draft. Resume preserves a decoded audio offset where available, without restoring a cancelled automatic transition. The originating task/question binding stays with the dictated thought.

Composer pastes and bulk replacement input remain editable drafts. Room pastes retain automatic submission. Empty exchanges return focus to the room so voice intake remains the default. A visible Resume control handles cancelled dictation. The new immediate Thinking state appears before provider admission; short grounded acknowledgements are cached and run alongside inference without another model request. A restrained white presence circle uses a WebAudio envelope during speech, a subtle thinking pulse/trail, and reduced-motion behavior.

Fixed the import-confirmation loop: an ordinary new coordinator exchange no longer deletes the previously shown discovery batch. The next input includes that durable preview, preserves the later-exchange confirmation guard, and repeated confirmation reuses existing imports. Search/import actions scope artifacts to the relevant exchange. Import narration includes the conversation's purpose and one clear question; source folder names are labeled Workspace, and internal IDs/paths are kept out of the spoken preview. Removed the serial model call previously used to rewrite search candidates. Codex search now combines native title-filter variants with a bounded recent-preview scan and reports its coverage.

Consumer ChatGPT history remains a separate integration gap. The installed generated public app-server schema has Codex thread/list source kinds and no consumer conversation-search method. Lounge reports this scope explicitly; it does not claim a consumer search occurred. The first-party tools in the main desktop app are not automatically available to a standalone coordinator. No browser extension, private desktop IPC, account-token access or broader native permission has been added.
