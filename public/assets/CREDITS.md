# Lounge chair mark

Created for Lounge using the built-in OpenAI image generation tool. The final mark is a tan side profile on burnt orange, refined from an earlier upholstered-chair concept. The original reference photograph is not distributed in this repository.

Master: `lounge-icon.png` (1024×1024). Browser favicon: `lounge-favicon.png` (64×64). The Mac build derives its multi-resolution `Lounge.icns` from the master.

Final generation prompt:

> A professional minimalist VECTOR LOGO exported as a clean PNG, flat SVG aesthetic, square app icon. Uniform solid burnt orange background #A74B2A, a single tan #E3CFAC silhouette of a mid-century swivel lounge chair seen from its exact SIDE PROFILE facing right. An elegant slender continuous shell, reclined back at left, slim long horizontal seat at right, narrow pedestal and simple horizontal foot. Thin negative-space orange seam line follows the seat and back. Sophisticated furniture-design studio identity, precise geometry, restrained and mature, no cartoon softness or puffy shapes. Exactly two solid inks, absolutely no texture, no grain, no gradients, no lighting, no shadows, no perspective. Shape edges smooth. No text or letters. Center the full chair with generous margin on all sides. Digital flat illustration on flat orange field.
